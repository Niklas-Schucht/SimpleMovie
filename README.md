  # SimpleMovie

  ## Setup

  The project requires Xcode and iOS 17.6 or newer.

  ### TMDB Token

  The app needs a TMDB read access token.

  1. Copy `SimpleMovie/Config/TMDBSecrets.example.plist`
  2. Rename the copy to `TMDBSecrets.plist`
  3. Replace `PASTE_YOUR_TMDB_ACCESS_TOKEN_HERE` with your TMDB read access
  token
